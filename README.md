# D2C Customer Churn Intelligence

## Part 2: RFM Segmentation & Retention Strategy

### Objective

Segment customers using RFM analysis and behavioral signals to support targeted retention planning.

### Repository Contents

- rfm_segmentation.ipynb
- segments.csv
- retention_strategy.md
- manual_review_cases.md
- README.md
- requirements.txt

### Methodology

1. Filtered orders up to snapshot date (2025-09-30)
2. Calculated Recency, Frequency, and Monetary metrics
3. Generated RFM scores
4. Created customer segments
5. Developed retention recommendations

### Segment Distribution

- Champions: 55
- Loyal Customers: 416
- Potential Loyalists: 612
- At Risk: 735
- Lost Customers: 582

### Key Insight

The At Risk segment is the largest group and should be prioritized for retention-focused interventions.
